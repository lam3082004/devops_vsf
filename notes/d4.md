## Decision: ngôn ngữ và chủ đề

- **Ngôn ngữ: Rust** (cargo 1.95.0, rustc 1.95.0)
  - Lý do: binary tĩnh → image `distroless/cc` hoặc `scratch` rất nhỏ, gần như 0 CVE OS package (M9)
  - Đánh đổi: **build chậm** (vài phút) → CI phải cache; cần cẩn thận với TLS backend và với việc đốt CPU trong runtime async
- **Chủ đề: Node registry** — sổ đăng ký các "node" (máy/agent) tự khai báo: tên, địa chỉ, vai trò, lần cuối thấy
  - Bảng `nodes` đóng vai trò bảng `items` trong đề; endpoint `/items` giữ nguyên tên theo đề, thao tác trên bảng `nodes`

## Schema bảng `nodes`

| Cột | Kiểu | Ràng buộc |
|---|---|---|
| `id` | BIGINT | PK, AUTO_INCREMENT |
| `name` | VARCHAR(200) | NOT NULL, UNIQUE |
| `address` | VARCHAR(100) | NULL (IP hoặc hostname của node) |
| `role` | VARCHAR(50) | NOT NULL, mặc định `worker` |
| `last_seen_at` | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP |

`POST /items` = đăng ký node mới (hoặc cập nhật `last_seen_at` nếu `name` đã có) · `GET /items` = danh sách node mới nhất.

## Ghi chú / lỗi gặp

| Vấn đề | Nguyên nhân | Cách sửa |
|---|---|---|
| Dòng log có **2 key `level`** | tự đặt trường `level = "fatal"` trong khi subscriber đã sinh `"level":"ERROR"` | đổi tên trường thành `event = "config_error"`; KQL `parse_json` chỉ giữ 1 key trùng nên rất khó debug |
| `/version` trả `dev` dù build với `GIT_SHA=...` | Cargo không build lại khi chỉ có biến môi trường đổi → `option_env!` giữ giá trị cũ | thêm `build.rs` với `cargo::rerun-if-env-changed=GIT_SHA`; kiểm chứng: rebuild → `{"sha":"test123abc"}`. Trong Docker mỗi lần build là container mới nên không gặp, nhưng **build local dễ tạo bằng chứng M2 sai** |
