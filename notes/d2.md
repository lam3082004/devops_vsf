## Ràng buộc: IP nhà là IP động (phát mạng từ điện thoại)

Máy làm việc đi Internet qua hotspot điện thoại → **IP công khai đổi thường xuyên** (đổi mỗi lần bật/tắt hotspot, đổi trạm, nhà mạng cấp lại).

Hệ quả:

| Ảnh hưởng | Chi tiết | Cách sống chung |
|---|---|---|
| Firewall MySQL (`ClientIPAddress`) | IP cũ hết tác dụng → kết nối DB timeout | Portal → Networking → **+ Add current client IP address** (Portal tự dò IP hiện tại) → Save. Xoá rule cũ để khỏi rác |
| Access restriction của Web App (D13, M6) | Chính mình bị 403 | Biến `allowed_ips` trong Terraform → sửa giá trị → apply lại (nhanh hơn sửa tay, và đúng tinh thần M8) |
| Bằng chứng M6 | **Hotspot và trình duyệt trên chính điện thoại đó dùng chung một IP công khai** → không thể dùng làm "IP bị chặn" | Cần **mạng thứ hai thật sự khác**: wifi trường/nhà, hotspot của người khác, hoặc trình duyệt trên điện thoại **khác** |
| Bảo mật | Mạng di động thường dùng CGNAT → IP được chia sẻ cho nhiều thuê bao ⇒ whitelist IP đó là mở cho cả người lạ cùng nhà mạng | Ghi vào `known-issues.md`; hướng đúng là Private Endpoint (S3) |

Lưu ý: trạng thái cuối theo M3 là firewall MySQL **chỉ** chứa outbound IPs của App Service, **không** chứa IP máy bạn. Rule `ClientIPAddress` chỉ là tạm để debug ở D2 → nhớ xoá.
